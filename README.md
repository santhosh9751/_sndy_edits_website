# Sndy Edits — High-Retention Video Editing Studio

Official portfolio & client portal website for **Sndy Edits** (`@_sndy_edits`), specializing in viral Instagram velocity edits, beat-synced transitions, and social media growth strategies.

## ✨ Features
- **Hero Mobile Preview**: Recreated Instagram mobile profile showcasing real `@_sndy_edits` handle, follower metrics, and top video highlights.
- **Top Reach Showcase**: Authentic reels fetched and verified directly from Instagram, complete with real view counts (22.9K, 13.8K, etc.) and embedded reel preview player.
- **Pricing & Packages**:
  - **Sndy Pro (₹5,000 / month)**: Full social media management, daily/weekly viral reel production, hook curation, trending sound selection, and scheduled uploads.
  - **Access to Templates Plan (₹2,000 / month)**: Subscriber-only vault containing custom Premiere Pro, After Effects, and CapCut project files.
- **Multi-Page Architecture**:
  - `index.html` — Homepage with hero showcase, trust badges, and studio highlights
  - `reels.html` — Dedicated video portfolio with category filters and interactive modal
  - `pricing.html` — Transparent package plans and feature comparison
  - `templates.html` — Exclusive locked portal for paying template subscribers
  - `enquiry.html` — Raw footage submission & direct WhatsApp onboarding
  - `admin.html` — Studio CMS to manage metrics, testimonials, and orders
- **Zero Dummy Data**: All media, stats, and profile assets are real.

## 🚀 Running Locally
```bash
npm install
node server.js
```
Open [http://localhost:4200](http://localhost:4200) in your browser.
